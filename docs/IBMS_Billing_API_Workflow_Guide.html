IBMS Billing System: End-to-End API Workflow & Testing Guide

Version 1.0 .NET 10 | ASP.NET Core QA & Backend Verified

This document provides the chronological, verified workflow of the IBMS Billing System APIs. It covers all 8 executed steps—from authentication and master rule setup to product cataloging and final deterministic financial calculation.

1. System Architecture & Sequential Flow

[1. Login (JWT Token)] ↓ [2. Tax Settings & Slabs (GST 18%)] ↓ [3. Product Category ("Computer Hardware")] ↓ [4. Product Inventory ("Logitech Mouse" @ ₹1,200)] ↓ [5. Customer Profile ("Rahul Sharma" - Telangana)] ↓ [6. Additional Charges Policy ("Standard Shipping" @ ₹75)] ↓ [7. Concurrency-Safe Number Generation ("INV-2026-0001")] ↓ [8. Master Financial Engine Calculation (Grand Total: ₹2,492.16)]

2. Step-by-Step API Specification

Step 1: User Authentication & Session

POST /api/auth/login

Business Purpose: Enforces multi-tenant data isolation and RBAC. Generates the JWT Bearer token needed for all protected APIs.

Request Body: 
{
  "email": "superadmin@ibms.com",
  "password": "SuperAdmin@123!"
}

Expected Output: 200 OK with access token and user claims.

Step 2: Tax Slabs & Configuration

POST /api/v1/settings/taxes/rates

Business Purpose: Invoices and products legally require tax rates. Registers a persistent 18% GST slab (id: 6, code: "GST_18").

Request Body: 
{
  "name": "GST 18%",
  "code": "GST_18",
  "taxType": "GST",
  "rate": 18.0,
  "description": "Standard GST 18% for Electronics and Peripherals",
  "isCompound": false,
  "isInclusive": false,
  "applicationLevel": "Item",
  "priority": 1,
  "effectiveFrom": "2026-01-01T00:00:00.000Z",
  "effectiveTo": null,
  "status": "Active"
}

Expected Output: 201 Created with generated tax rate ID.

Step 3: Product Category Catalog

POST /api/v1/categories

Business Purpose: Classifies inventory into business groups for sales analytics, reporting, and grouping.

Request Body: 
{
  "name": "Computer Hardware",
  "description": "Laptops, Desktops, Keyboards, Mice and Peripherals",
  "status": "Active"
}

Expected Output: 201 Created with category ID.

Business Purpose: Registers sellable goods with category, GST HSN code (8471), standard unit price (₹1,200), and max allowed discount.

Step 6: Additional Charges Policy

POST /api/v1/settings/charges

Business Purpose: Predefines tenant-wide shipping rules with minimum order threshold (₹500.00), maximum cap (₹200.00), and taxable GST flag.

Request Body: 
{
  "name": "Standard Express Shipping",
  "code": "SHIP_EXP",
  "description": "Ground delivery within 2-3 business days",
  "chargeType": "Shipping",
  "calculationType": "Fixed",
  "amount": 75.0,
  "minInvoiceAmount": 500.0,
  "maxChargeAmount": 200.0,
  "isTaxable": true,
  "taxCategory": "Standard",
  "status": "Active"
}

Expected Output: 201 Created with charge rule ID.

Step 7: Concurrency-Safe Invoice Number Generation

POST /api/v1/settings/numbering/generate

Business Purpose: Prevents duplicate/missing invoice sequence numbers using thread-safe, atomic database sequence locking.

Request Body: 
{
  "documentType": "Invoice",
  "transactionDate": "2026-09-21T00:00:00.000Z"
}

Expected Output: 200 OK returning INV-2026-0001.

Step 8: Master Financial Calculation Engine (Checkout)

POST /api/v1/financial/calculate

Business Purpose: The core computing engine of the billing system. Applies items, line discounts, coupons, taxes, and shipping in a strict, deterministic sequence.

Request Body: 
{
  "items": [
    {
      "name": "Logitech Wireless Mouse M331",
      "productCode": "PRD-0001",
      "unitPrice": 1200.0,
      "quantity": 2,
      "lineDiscountType": "Percentage",
      "lineDiscountValue": 10.0,
      "taxRateId": 6,
      "taxCode": "GST_18",
      "taxRatePercent": 18.0,
      "isTaxInclusive": false
    }
  ],
  "invoiceDiscount": {
    "discountType": "Percentage",
    "value": 5.0,
    "ruleCode": "SPECIAL5",
    "overrideReason": "Customer loyalty discount"
  },
  "charges": [
    {
      "name": "Standard Delivery",
      "chargeCode": "SHIP_STD",
      "chargeType": "Shipping",
      "calculationType": "Fixed",
      "amount": 60.0,
      "isTaxable": true,
      "taxRatePercent": 18.0
    }
  ],
  "transactionDate": "2026-09-21T04:43:53.778Z",
  "pricesIncludeTax": false,
  "currency": "INR"
}

Deterministic Calculation Arithmetic:

Calculation Step Formula Amount
1. Line Gross Amount 2 mice × ₹1,200.00 ₹2,400.00
2. Line Item Discount (10%) 10% of ₹2,400.00 = -₹240.00 ₹2,160.00 (Net Line Amount)
3. Order-Level Discount (5%) 5% of ₹2,160.00 = -₹108.00 ₹2,052.00 (Taxable Base)
4. Product GST (18%) 18% on ₹2,052.00 +₹369.36
5. Additional Delivery Charge Fixed shipping fee +₹60.00
6. Tax on Delivery Charge (18%) 18% on ₹60.00 +₹10.80
7. Final Grand Total ₹2,052.00 + ₹369.36 + ₹60.00 + ₹10.80 ₹2,492.16

Expected Output: 200 OK with line breakdown and grandTotal: 2492.16.
